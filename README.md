# Genjeez Waitlist

Fullstack waitlist application for **Genjeez**.

## Overview
This app collects and manages early signups for the Genjeez platform.  
Built with Streamlit for fast iteration and deployment.

## Tech Stack
- Python
- Streamlit
- streamlit-shadcn-ui

## Requirements
- **Python 3.11** (recommended)

## Setup (Local)
```bash
# create virtual environment
python -m venv venv

# activate
source venv/Scripts/activate   # Windows (Git Bash)
source venv/bin/activate     # macOS/Linux

# install dependencies
pip install -r requirements.txt

# run the app
streamlit run app.py
